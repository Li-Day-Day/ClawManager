# D 总览未就绪时的独立记录读取

当前后台总览固定返回 `503 not_ready`，而配置和四类任务列表已有独立认证读取接口。此前前端先读总览，导致这些可用记录也无法进入。本轮增加明确的“记录读取”状态：总览未就绪时分别读取配置和四类列表，并明确说明健康、恢复就绪和全局计数尚不可用。完整总览恢复后，刷新会重新进入原总览流程。

只有总览的准确 `503/not_ready` 会进入该流程。各资源独立的同类响应显示“未就绪”，不会显示为零或空记录；经过验证的真实空列表仍可显示空态。所有资源均未就绪时保留原不可用页。401、403、其他异常及非法响应不会发布部分记录，示例来源不会切换成真实数据。

读取前后检查配置可用性、安装、配置版本、行版本和生效状态，并在异步读取前复制校验基准。非空列表与配置共同校验安装归属；配置不可用且所有列表为空时，归属保留 null。分页沿用每页 50 项、opaque cursor、重复记录/游标循环和 consistency 校验，并再次检查配置和安装。取消、刷新或后台轮询开始后，不接受旧分页结果。

配置可用时可以进入已有配置历史；列表可用时可选择任务。当前后台四类详情及事件/日志仍返回未就绪，相关控件会显示既有错误/不可用状态。本轮没有补造 Owner 事实或完成这些后端读取源，也未增加写入、正式 migration 或生产授权。显式示例的共享总览布局保持原样。

[r37 回执](evidence/system-backup-d-live-records-local-20261015-r37.json)及[原始输出](evidence/system-backup-d-live-records-local-20261015-r37.txt)记录一次正常运行：180 项 Node 检查通过、0 失败/跳过，包含本轮新增 15 个主测试及 25 个子测试。覆盖独立可用性、全不可用、权限错误、来源、归属、配置漂移、分页、取消和总览恢复；既有详情、活动、配置历史及五语言检查一并通过。测试使用关闭字段集的模拟 HTTP 响应，没有请求实际服务。

用户确认暂无依赖环境，由用户随后构建并截图。本地没有安装依赖，没有执行 TSX 类型检查、完整构建、React 渲染或浏览器验收，也未产生测试构建产物。源码摘要为运行后记录，不能替代冻结构建清单。验收入口和截图场景见[操作者说明](system-backup-d-frontend-manual-review-20261015.md)。六项整体范围仍未完成。
